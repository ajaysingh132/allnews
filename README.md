# GBSBFORYOU All News — Hindi Free News Dashboard

Mobile-first, free-first dashboard for collecting news links and short RSS descriptions, preparing original Hindi summaries and analysis, and tracking human editorial review.

## Files
- `hindi-news-dashboard.html`: standalone mobile-friendly dashboard.
- `scripts/fetch-news.mjs`: no-dependency RSS/Atom metadata collector.
- `.github/workflows/refresh-news-feed.yml`: scheduled feed refresh every four hours plus manual workflow trigger.
- `feed-data.json`: generated by GitHub Actions and read by the dashboard after the first successful run.

## Free-first policy
- No paid API keys are required.
- The collector stores headlines, short descriptions, source names, links and dates only.
- It does not copy full articles or images and does not publish news automatically.
- RSS availability and formats can change. Check the workflow run and `sourceResults` in `feed-data.json`.
- GitHub Pages is a static host; dashboard records entered by a person stay in that browser's localStorage and are not shared across devices.
- Editorial approval is mandatory before anything is published externally.

## How to use on mobile
1. Open the GitHub Pages URL ending in `/hindi-news-dashboard.html`.
2. Tap **नवीनतम फ़ीड लोड करें** after the scheduled feed file exists.
3. Add a story manually if a feed is unavailable.
4. Write the summary and analysis in Hindi, keep the original source link, and mark the record reviewed/approved.
5. Export JSON periodically to back up local browser records.

## Free RSS sources currently configured
- PIB Hindi RSS
- UN News RSS
- BBC World RSS
- DW News RSS

These are source-discovery feeds, not a licence to republish full articles. Check each source's content-use policy before reuse. RSS collection may fail when a source is unavailable or changes its feed format.

## Workflow
GitHub Actions runs every four hours. To run immediately: repository → **Actions** → **Refresh free news RSS metadata** → **Run workflow**. If the workflow cannot push to the branch, check repository Actions permissions and workflow-run logs.

## Editorial standard
Claim → source → primary evidence → counter-evidence → context → interests → impact → root cause → possible solution → conclusion. Keep facts, official statements, allegations, analysis and opinion distinct. AI must never auto-publish.
